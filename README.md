 Redemption Clothing

1. Project Description

Redemption Clothing is a Christian-inspired retail clothing website designed to showcase clothing products based on faith, identity and Christian messages.

Part 2 of the project focuses on improving the website by using CSS to create a more attractive, organised and responsive design.

2. Purpose of Part 2

The purpose of Part 2 was to style the existing HTML website and improve the user experience.

The website was designed using an external CSS stylesheet so that the same styling could be applied across the different pages.

3. Website Pages

The website contains the following pages:

* Home
* About Us
* Products
* Gallery
* Contact

4. CSS Features Used

The following CSS features were used in Part 2:

* External stylesheet
* Base styles
* Typography
* Colours
* Spacing and margins
* Flexbox and grid layouts
* Borders and rounded corners
* Hover effects
* Responsive images
* Relative units such as `em`, `rem` and percentages
* Media queries and breakpoints
* Responsive design for different screen sizes

5. Colour Scheme

The main colour scheme used for the website is:

* Black
* White
* Baby pink

Black and white were used as the main colours to create a simple clothing-brand style, while baby pink was added as an accent colour.

6. Responsive Design

The website was designed to work on different screen sizes.

Media queries were used to change the layout when the screen becomes smaller. For example, product and gallery layouts can change from multiple columns to a single-column layout on smaller screens.

 7. Images

The images used on the website are stored inside the `images` folder.

The HTML pages use relative image paths such as:

```html
<img src="images/gallery1.jpg" alt="Redemption Clothing">
```

Keeping the images inside the project folder allows the website to continue displaying them when the project is moved to another computer or uploaded to GitHub.

9. How to View the Website

1. Download or clone the repository.
2. Open the Redemption project folder.
3. Open `Home.html` in a web browser.
4. Use the navigation links to view the other pages.
